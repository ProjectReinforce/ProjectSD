# 게임 규칙

Sweepin' Dreams 의 코어 규칙을 한 곳에 정리. 스킬/적/UI의 "게임이 어떻게 작동하는가"에 직결되지만, 구현 상세(매니저 구조, 씬 구조)는 [systems/managers.md](../systems/managers.md), [systems/scene-structure.md](../systems/scene-structure.md) 참조.

## 1. 스킬 슬롯

- 플레이어당 **최대 6슬롯** (액티브 + 패시브 합계).
- **시작 패시브도 슬롯 포함.** (없는 캐릭터는 없음)
- 슬롯 수는 **설정에서 변경 가능** (기본 6).
- 슬롯이 모두 찬 상태에서 레벨업:
  - 기존 스킬 레벨업만 선택지에 등장.
  - 모든 스킬이 만렙이면 **능력치(스탯 부스트) 선택지**로 전환.
- **진화** 시 2슬롯이 1슬롯으로 합쳐져 빈 슬롯 생성 → 새 스킬 획득 가능.

## 2. 경험치 & 레벨업

- **팀 공유 경험치.** 적 사망 시 경험치 오브 드롭.
- 플레이어가 **5m 이내 접근 시 자석처럼 끌려옴** (흡수 범위는 패시브로 확장 가능).
- 레벨업은 팀 전체 동시 발생. 모든 플레이어가 동시에 선택 화면을 본다.
- 경험치 곡선 공식:
  ```
  필요 경험치 = 100 + (레벨 × 20)
  ```
  레벨 1→2: 120, 5→6: 200, 10→11: 300, 15→16: 400, 20→21: 500.
- 보스 등장 시점 **레벨 18~22 도달 목표** (2인 기준). 총 경험치는 타이머 길이에 따라 밸런싱 단계에서 재조정.

## 3. 사망 & 부활

- 체력 0 → **사망** → 10초 부활 타이머.
- 부활: **체력 50% 상태로 안전 지점 스폰**.
- 전원 사망 시 **게임 오버** (결과 화면 → 실패).
- 사망/부활 UI는 [flow-design.md § 3.4.4](flow-design.md) 참조.

## 4. 인원 스케일링

플레이 인원수에 따라 적의 체력/수량/경험치가 자동 조정된다. 기준 2인.

| 인원 | 체력 배율 | 동시 적 수 배율 | 경험치 배율 |
|---|---|---|---|
| 1 (솔로) | 0.6x | 0.6x | 1.0x |
| 2 (기준) | 1.0x | 1.0x | 1.0x |
| 3 | 1.4x | 1.3x | 0.95x |
| 4 | 1.8x | 1.6x | 0.9x |

*경험치는 팀 공유이므로 인원이 많을수록 개인당 레벨업 속도가 약간 느려진다. 4인은 협동·시너지가 필수.*

스폰 타이밍·난이도 곡선 수식은 [systems/spawn-rules.md](../systems/spawn-rules.md).

## 5. 혼돈 스킬 규칙

- **레벨 10 / 20 / 30** 에서 각 1회씩, 최대 3회 선택 (확정).
- 게임 규칙 자체를 변경하는 스킬. 4등급 체계(일반/희귀/영웅/전설).
- **마지막 선택 (레벨 30, 보스 결정):** 각 플레이어가 3개 중 1개 선택 → **선택되지 않은 스킬 중 랜덤 1개가 보스에게 부여**.
- 레벨업 UI에서 등급은 색상으로 구분.

개별 혼돈 스킬 19종과 보스 적용 효과는 [skills/INDEX.md § 혼돈](skills/INDEX.md), 보스 적용 수식은 [enemies/boss.md](enemies/boss.md).

## 6. 호스트 이탈 / 비상 보스전

- 호스트 연결 끊김 감지 → **게임 일시정지, 5초 재연결 대기**.
- 재연결 성공 → 정상 재개.
- 재연결 실패 → **새 호스트 자동 전환 + 비상 보스전 시작** (일반 적 스폰 중단, 보스 즉시 등장).
- 네트워크 복구 상세는 [systems/network-sync.md](../systems/network-sync.md).

## 7. 플레이어 연결 끊김 (호스트 아님)

- 해당 플레이어 **사망 처리 + 30초 재접속 대기**.
- 재접속 시 안전 지점 부활.
- 실패 시 영구 퇴장 처리.

## 8. 아이템 / 드랍

- **경험치 오브** — 모든 적 드롭. 자석 흡수.
- **자석 (기타 아이템)** — 맵 남은 경험치 조각 전부 흡수.
- **물약** — 체력 소량 회복. "체력 회복량 증가" 패시브와 시너지.
- **정수** — 엘리트 드롭. 선착순 2개 제한. 상세는 [overview.md § 7](overview.md).
- **무기** — 모든 적 드롭 (매우 낮은 확률). 선착순, 조합 우선 UI 표시.

## 9. 클리어 / 실패 조건

| 조건 | 결과 |
|---|---|
| 보스 처치 | 클리어 → 결과 화면 |
| 전원 사망 | 실패 → 결과 화면 |
| "다시 하기" | 대기실 복귀 (방 유지) |
| "나가기" | 타이틀 화면 (방 퇴장) |
