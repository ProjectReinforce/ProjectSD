## 5. 공격 패턴 (3페이즈)

### Phase 1 — HP 100%~60%
- 가장 가까운 플레이어 추적
- **5초마다 전방 부채꼴 충격파** (데미지 40)
- 접촉 시 강한 넉백
- **전이 조건:** HP ≤ 60%

### Phase 2 — HP 60%~30%
- 이동 속도 **3.0으로 증가**
- 충격파 발사 간격 **3초로 단축**
- **10초마다 랜덤 플레이어 위치에 원형 지대 생성** (3초 후 폭발, 데미지 60)
- **전이 조건:** HP ≤ 30%

### Phase 3 (Enrage) — HP 30%~0%
- 광폭화: 이동 속도 **3.5**, 접촉 데미지 **50**
- 충격파 발사 간격 **2초**
- **원형 지대 2개 동시 생성**
- **5초마다 맵 전체에 3초간 슬로우** (플레이어 속도 50% 감소)

## 6. 혼돈 스킬별 보스 효과 (SSOT)

**레벨 30 선택**의 미선택 혼돈 스킬 중 랜덤 1개가 보스에게 부여된다. [../rules.md § 5](../rules.md) 규칙 참조.

| 혼돈 스킬 | 보스 적용 효과 |
|---|---|
| [유리대포](../skills/chaos/glass-cannon.md) | 보스 체력 50% 감소, 모든 공격 데미지 2배. 빠른 클리어 가능·실수 시 즉사 |
| [연쇄 폭발](../skills/chaos/chain-explosion.md) | 보스가 처치한 플레이어 위치에서 폭발 (3초 후, 데미지 40, 범위 5m). 부활 후 즉시 도망 |
| [폭주 모드](../skills/chaos/berserk.md) | 체력 30% 이하 시 공격 쿨타임 50% 감소, 이동 속도 4.0. Phase 3 극한 |
| [가속 엔진](../skills/chaos/acceleration.md) | 보스전 시작 후 매 1분마다 공격력 +25%, 이동 속도 +0.3. 장기전 불리 |
| [단결](../skills/chaos/unity.md) | 플레이어 상호 5m 이상 이격 시 보스 데미지 +40%. 뭉쳐야 함 |
| [도박꾼](../skills/chaos/gambler.md) | 보스 충격파가 3갈래로 분기. 회피 난이도 증가 |
