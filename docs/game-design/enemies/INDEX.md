## 설계 원칙

| 구간 | 시간 | 난이도 방향 |
|---|---|---|
| 초반 | 0~3분 | 플레이어가 강화 조합을 구축하는 시간. 적의 위협도 낮음 |
| 중반 | 3~7분 | 강화가 시너지 내기 시작. 밀집도/강도 증가 |
| 후반 | 7~10분 | 빌드 완성. 최대 난이도 |
| 보스전 | **현재 15분~** (밸런싱에서 10분 단축 가능) | 팀워크 필요. 2~5분 소요 |

## 성능 최적화 원칙

- 적 오브젝트 풀링 필수 (최대 100개 풀)
- 화면 밖 적은 간소화 AI
- NavMesh 대신 단순 추적 (성능 우선)
- 멀리 있는 적은 저해상도 모델 (LOD)

## 밸런싱 가이드라인

- **플레이 타임 목표:** 보스 등장 10~15분, 총 12~17분 (보스전 포함). 실패 시 재도전 장벽 낮게.
- **레벨 진행:** 보스 등장 시점 레벨 18~22 (2인 기준), 평균 강화 6~8개, 진화 1~2개.
- **생존:**
  - 초반: 거의 죽지 않음
  - 중반: 이동 실수 시 위험. 시너지 가면 안정화
  - 후반: 밀집도 긴장감. 강한 빌드는 압도 가능
  - 보스: 팀워크 필수. 혼돈 스킬에 따라 난이도 극변
