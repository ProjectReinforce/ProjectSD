# 적 설계서: 무리형 (Swarm)

## 1. 메타

| 항목 | 값 |
|---|---|
| 엔티티 ID | `enemy_swarm` |
| 한국어 이름 | 무리형 |
| 영어 이름 | Swarm |
| 분류 | 기본 |
| 등장 시점 | 0분~ |
| 등장 비율 | 10% |
| 최종 업데이트 | 2026-04-18 |

## 2. 컨셉

한 방향으로만 이동하며 5~10마리씩 무리로 등장. 이동 경로 예측을 요구하여 회피 가능. 플레이어 추적 없음.

## 3. 스탯

| 레벨 | HP | 데미지 | 이속 | 공격 범위 | 점수 |
|---|---|---|---|---|---|
| 1 | 60 | 8 | 4.0 | 0.5m | 8 |

## 4. 이동 패턴

- **이동 타입:** SwarmMovement (랜덤 방향 직진)
- **참조:** `Assets/Scripts/Adapter/Entity/Enemy/Movement/` 내 SwarmMovement 구현
- **특수 동작:** 일정 시간 직진 후 소멸. **5~10마리 그룹 스폰** (SpawnManager가 한 번에 그룹 단위 생성).

## 5. 공격 패턴

접촉 데미지.

## 6. 보상

- **경험치:** 8 (개별, 그룹이 전멸하면 누적 많음)

## 7. 데이터 계약

- **SO 타입:** `EnemyData`
- **에셋 경로:** `Assets/Data/Enemies/swarm.asset`
- **주요 필드:** `groupSize: [5..10]`, `lifetime`

## 8. 네트워크

- 그룹 스폰 시 묶음 RPC로 효율화 권장.
