## 2. 패시브 스킬 (19종)

모든 패시브는 최소 1개의 진화에 연결되거나 범용으로 활용 가능. 버리는 선택지 없음.

| # | 패시브 | 효과 | 진화 연결 |
|---|---|---|---|
| 1 | 투사체 속도 증가 | 투사체 이동 속도 | 표창 → 폭렬 표창 |
| 2 | 투사체 개수 증가 | 투사체형 발사 수 +1 | 매직 미사일 → 체인 미사일 |
| 3 | 스킬 범위 증가 | 이펙트 크기·데미지 범위 | 장검 → 검무 / 회오리 → 대선풍 |
| 4 | 스킬 유지 시간 증가 | 장판/설치 지속시간 | 번개 → 뇌전역 |
| 5 | 공격력 증가 | 모든 스킬 데미지 | 개미지옥 → 나락 |
| 6 | 넉백 거리 증가 | 밀어내기 거리 | 부메랑 → 그래비톤 부메랑 |
| 7 | 체력 회복량 증가 | 회복 효과 | 성역 → 심판의 성역 |
| 8 | 치명타 데미지 증가 | 치명타 배율 | 자동포탑 → 미니건 포탑 |
| 9 | 스킬 쿨타임 감소 | 재사용 대기 단축 | 저주인형 → 역병 인형 |
| 10 | 최대 체력 증가 | HP 수치 | 범용 |
| 11 | 이동속도 증가 | 이속 | 범용 |
| 12 | 방어력 증가 | 받는 데미지 감소 | 범용 |
| 13 | 경험치 획득량 증가 | EXP 드롭 | 범용 |
| 14 | 체력 재생 증가 | 초당 회복 | 범용 |
| 15 | 치명타 확률 증가 | 치명타 확률 | 범용 |
| 16 | 피격 시 무적 시간 증가 | 무적 프레임 연장 | 범용 |
| 17 | 적 처치 시 체력 회복 | 킬당 소량 회복 | 범용 |
| 18 | 경험치 획득 범위 증가 | 흡수 범위 확대 | 범용 |
| 19 | 럭 (리롤) | 강화 선택지 리롤 | 범용 |

패시브는 수치 기반이므로 스킬당 개별 문서 대신 본 인덱스에서 관리. 진화 조건에 등장하는 패시브만 관련 스킬 파일 "진화 경로" 섹션에서 참조.

## 3. 진화 테이블 (10종)

액티브 + 패시브 모두 최대 레벨일 때 발동. 2슬롯 → 1슬롯으로 합쳐진다.

| 액티브 | 패시브 조건 | 진화 스킬 |
|---|---|---|
| 표창 | 투사체 속도 증가 | 폭렬 표창 |
| 매직 미사일 | 투사체 개수 증가 | 체인 미사일 |
| 장검 | 스킬 범위 증가 | 검무 |
| 번개 | 스킬 유지 시간 증가 | 뇌전역 |
| 개미지옥 | 공격력 증가 | 나락 |
| 부메랑 | 넉백 거리 증가 | 그래비톤 부메랑 |
| 성역 | 체력 회복량 증가 | 심판의 성역 |
| 자동포탑 | 치명타 데미지 증가 | 미니건 포탑 |
| 저주인형 | 스킬 쿨타임 감소 | 역병 인형 |
| 회오리바람 | 스킬 범위 증가 | 대선풍 |

*#11~24 의 진화 조합은 미정. [overview.md § 10](../overview.md).*

## 5. 설계 노트

### 성능 관리

- 장판/설치형 스킬은 **동시 존재 수 상한 + 오브젝트 풀링 필수**.
- **연쇄 폭발 안전장치:** 프레임당 연쇄 횟수 상한. 무한 루프 방지.
- **광란 혼돈 스킬:** 쿨타임 0.1초 시 투사체/이펙트 폭증. 동시 존재 수 제한.
- **메아리:** 24종 각각에 대한 재생 로직 필요. 진화 스킬 복제 범위 별도 결정.
- **출입제한구역 표지판:** 벽 충돌 + 시점 이동 + 순간이동의 네트워크 동기화 복잡. **후순위 구현 권장.**

### 보류 사항

- **마력 시스템:** 초기 프로토타입 제외. 쿨타임 트레이드오프로 유사 효과.
- **분신 스킬:** 버그 리스크로 제외. 추후 범위 제한하여 재검토.
- **쇠사슬 스킬:** 두더지와 역할 중복 + 네트워크 복잡성으로 제외.
